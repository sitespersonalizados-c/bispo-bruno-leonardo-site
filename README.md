# 🌐 Site Oficial — Bispo Bruno Leonardo

Projeto de website institucional desenvolvido com foco em performance, responsividade e experiência do usuário.

---

## 📖 Sobre o Projeto

Este site foi criado para centralizar conteúdos do Bispo Bruno Leonardo, incluindo:

* 🙏 Orações diárias (manhã, noite e meia-noite)
* ✨ Campanhas espirituais (Iluminados, Efata e outras)
* 🎥 Portal de vídeos
* 👶 Espaço infantil
* 📍 Informações sobre sedes
* 💳 Área de ofertas

O objetivo é oferecer uma navegação simples, rápida e acessível para todos os usuários.

---

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (puro)
* AOS (animações de scroll)

---

## ⚡ Performance

O projeto foi otimizado com foco em:
